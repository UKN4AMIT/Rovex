# ROVEX — Classic Travel Journal

A clean, responsive, classic editorial travel website built with plain HTML, CSS and JavaScript. No build tools, package installation or API keys are required.

## Run locally
1. Extract the ZIP.
2. Open the `ROVEX_Classic_Travel` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.
4. The site works in a modern browser. Internet is required for Google Fonts and remote Unsplash photography.

## Working demo features
- Responsive navigation and mobile menu
- Destination search and category filters
- Destination detail dialogs
- Save/remove destinations using browser localStorage
- Saved places shortlist
- Trip planner with indicative daily-cost estimates and itinerary outline
- Newsletter form demo (stores addresses only in this browser)
- Contact form demo (stores messages only in this browser)
- Toast feedback and reduced-motion support
- Basic SEO title, description, canonical, Organization schema, robots.txt and sitemap.xml

## Important limitations
This is a front-end demonstration. It does not send emails, process bookings, collect data on a server, provide live prices or connect to Supabase. Newsletter subscriptions, contact messages and saved places are stored locally in the current browser only. Budget figures are editorial estimates and exclude transport to/from the destination. Verify current prices, routes, access and local conditions before publishing.

For the CSET489 handbook's final VPS/WordPress requirement, this static demo is not a substitute for a fresh WordPress installation on a VPS. It can be used as a design/prototype and demonstration, but the required WordPress, SEO plugin, Search Console, GA4, backups and evidence must be completed separately.
